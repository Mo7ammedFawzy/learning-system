باختصار

في علاقة @OneToMany و @ManyToOne من الناحيتين، الـ foreign key موجود في ناحية الـ many، فهي الـ owning side.

وقت الـ flush، الـ Hibernate بيبني الـ INSERT من line.getOrder() بس، والـ collection اللي في الـ Order مابيبصلهاش.

لو ضفت الـ line في order.getLines() بس، الـ order_id هيتكتب NULL، فاعمل الناحيتين في helper واحد.

// Order 42 is managed.
// OrderLine.order: @ManyToOne @JoinColumn(name = "order_id")
// Order.lines:     @OneToMany(mappedBy = "order")
OrderLine line = new OrderLine("SKU-7", 2);
line.setOrder(order);              // owning side
order.getLines().add(line);        // inverse side (mirror)
em.persist(line);                  // id 101 from order_line_seq
em.flush();

-- SQL at flush
insert into order_line (order_id, qty, sku, id)
  values (NULL, 2, 'SKU-7', 101)
-- nothing is written for order.lines:
-- the mappedBy side is never read
