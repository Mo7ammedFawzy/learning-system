باختصار

كل class ليه مكان واحد بس لـ extends، وصف أماكن لـ implements: مينفعش اتنين base class، لكن interfaces كتير تنفع.

أي field في interface بيبقى public static final، قيمة واحدة لكل الـ classes، فالـ count++ عليه compile error.

الحل: الـ default method في الـ interface تنادي abstract method، وكل class يمسك الـ count بتاعه.
