Variance
List<String>  a = new ArrayList<>();
List<Integer> b = new ArrayList<>();
System.out.println(a.getClass() == b.getClass());
true   (both are class java.util.ArrayList)

Two different types at compile time, one class at run time. There is no List<String>.class: past the groove both tins are the same raw List.

The tin is the object, the raised tag its type argument, the sign the declared type with what it lets you do (get, add). Left of the groove is javac, right of it the JVM: the blade is type erasure, so the probe, getClass() and instanceof only ever meet a plain List.
